# RealQuickRealty

This repository is a proof-of-concept for an AI-powered real estate lead management and property comps system.

### Features:
1. Lead capture form (public-facing)
2. AI-powered lead qualification
3. Integration with live real estate APIs for property comps
4. Automated email forward to agent after AI processing

### Project Structure:
- **backend/**: Contains the server-side logic, APIs, and integrations
- **frontend/**: Includes the Next.js application for the lead form and dashboard
